SATHIYA PRIYA — PORTFOLIO

Files:
- index.html: site content
- style.css: responsive styling
- script.js: menu, reveals, filters and active navigation
- assets/profile.jpg: uploaded profile photo
- assets/Sathiya-Priya-Resume.pdf: downloadable resume

HOW TO RUN
1. Open this folder in VS Code.
2. Right-click index.html and choose "Open with Live Server" (if installed).
   Alternatively, double-click index.html to open it in a browser.
3. Edit contact information and project descriptions in index.html as needed.

The project cards use CSS artwork, not actual screenshots or links to live projects.
Fonts load from Google Fonts; offline fallback fonts are included in CSS.
